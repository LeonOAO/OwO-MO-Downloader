# OwO 平台影音｜小幫手 v1.0.3

公開版本：v1.0.3  
內部建置：2026.09.15-meta-quality-labels-default-worker

## 本版調整

- 預設 Worker 已內建，既有 localStorage 自訂網址仍優先。
- Facebook 僅明確 SD 欄位顯示 `SD`。
- 一般 playable、video 與 og:video 來源顯示 `原始畫質`。
- URL 或 DASH 有實際高度時優先顯示實際解析度。
- 完全沒有品質資訊時顯示 `未知畫質`。
- Instagram 與 Threads 原有品質規則保留。

## 完整保留

YouTube Media Session Cache、ANDROID_VR、高畫質合併、Log 自動清除與複製、Facebook Stories、Instagram Crawler View、Instagram Media API、Threads、MP4、M4A、MP3、WAV 與 Cookie 表單均保留。
